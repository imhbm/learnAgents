# 🚀 learnAgents

A hands-on playground to **build, experiment, and learn AI agents** using Python, Langfuse, LangSmith, OpenAI, and tool-based reasoning.

---

## ✨ What is this?

**learnAgents** is a Python project designed to help you:

✅ Build AI agents that reason step by step  
✅ Integrate tools like weather lookup and system commands  
✅ Understand observability using Langfuse decorators  
✅ Explore modern agent architectures with a “plan → action → observe → output” loop

This project is perfect for developers, learners, and researchers who want to go beyond chatbots and create action-taking agents.

---

## 💡 Key features

- 🌦️ **Weather tool** → Get live weather by city  
- 💻 **Command tool** → Run system commands safely  
- 🧠 **Agent loop** → Plan → Action → Observe → Output  
- 📊 **Observability** → Langfuse + LangSmith integration  
- 🔌 **OpenAI GPT-4o** → Natural language reasoning
